Security check: Run mt --fingerprint directly on the tlbx host, or obtain its fingerprint from the administrator over a trusted channel. Compare that trusted value with the SHA-256 fingerprint in your browser’s certificate viewer before entering a password. Step 2: Install Certificate

Mobile

iOS / iPadOS (Detected)

  1. Tap "Install Profile" above
  2. Open Settings app
  3. Tap Profile Downloaded (near the top)
  4. Tap Install, enter passcode if prompted
  5. Go to Settings → Updates / Info → Certificate Trust Settings
  6. Enable full trust for tlbx Certificate

Android (Detected)

Download Certificate
  1. Download tlbx-ca.crt above. Do not open the file from Chrome or Downloads.
  2. Open Android Settings → Security & privacy → More security settings → Encryption & credentials → Install a certificate. Do not use Network preferences → Install certificates; that Wi-Fi route is for a different purpose.
  3. Choose CA certificate, then select tlbx-ca.crt from Downloads. Do not choose VPN & app user certificate; that option requires a private key.
  4. Verify the fingerprint against the value obtained directly from the host or a trusted administrator

If Android says a private key is missing, leave the installer and restart from Security & privacy. Menu names vary by Android version and manufacturer.

Desktop (Detected)

Then run as Administrator in the download folder:

certutil -addstore Root tlbx.pem

Then run in Terminal from the download folder:

sudo security add-trusted-cert -d -r trustRoot \ -k /Library/Keychains/System.keychain tlbx.pem

Then run in Terminal from the download folder:

sudo cp tlbx.pem /usr/local/share/ca-certificates/tlbx.crt sudo update-ca-certificates

Verify in Your Browser

After installing, verify the connection is secure:

  1. Click the padlock icon in your browser's address bar
  2. Click Certificate or Connection is secure
  3. Find the SHA-256 fingerprint
  4. Compare it with the fingerprint obtained directly from the host or a trusted administrator
Security Warning: Never enter passwords or sensitive information until you have verified the fingerprint matches. If your browser shows a certificate warning after previously working, re-verify the fingerprint before proceeding.
